# Results

CSV files summarizing model performance, final selection, and test set evaluation. Generated by scripts 05-08.

Key files:

- `official_workflow_comparison.csv` - Cross-validated metrics for all 19 official workflows
- `final_selection.csv` - The selected best workflow and its training metrics
- `test_metrics.csv` - Test set performance (ROC AUC, accuracy, sensitivity, specificity)
- `best_workflow_confusion_matrix.csv` - Confusion matrix for the final model on test data
- `split_summary.csv` - Train/test split sizes and date ranges
- `model_coefficients.csv` - Standardized coefficients from the selected model
